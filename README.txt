WEDDING INVITATION STARTER

1. Open index.html in a browser to preview the site.
2. Replace [Bride's Name], [Groom's Name], and the family placeholders in index.html.
3. Replace [Venue to be added] with each event's venue.
4. Add your photos to the images folder using these exact filenames:
   - bride.jpg
   - groom.jpg
   - together.jpg
   The image files can be JPG, but keep the filenames as shown.
5. Edit colours, fonts and spacing in style.css.

This is a static, mobile-first website. It has no RSVP, gifting, database or backend.
You can publish the folder using GitHub Pages, Cloudflare Pages or Netlify.


ADDITIONAL PERSONALISATION (family + venues)
- In index.html, replace [Bride's Family Name] and [Groom's Family Name].
- Replace [Wedding Venue Name] and [Reception Venue Name].
- Find the two map-link URLs containing YOUR+WEDDING+VENUE and YOUR+RECEPTION+VENUE.
  Replace each query value with your venue name/address (use + between words), or paste
  your exact Google Maps share URL between the href quotes.
- The Wedding Ceremony card has the wedding venue/map link.
- The Reception card has the reception venue/map link.
